# Frontend Development

For frontend design, implementation, redesign, or UI polish tasks, use the frontend-design skill.

Follow the project's existing architecture and design system.

Prioritize distinctive visual design, accessibility, responsive behavior, and production-quality implementation.

Validate the result with available build tools and browser inspection.

## Project Skills

- `frontend-design`: `.agents/skills/frontend-design/SKILL.md` — primary frontend workflow supplied by the project owner.
- `frontend-skill`: `.agents/skills/frontend-skill/SKILL.md` — additional OpenAI guidance for visual hierarchy, composition, and interaction design; apply where relevant to the requested interface.
- `playwright`: `.agents/skills/playwright/SKILL.md` — browser automation for inspecting and validating frontend behavior when the required tooling is available.

Read the relevant SKILL.md before using a skill. Project requirements and existing architecture take precedence over generic design defaults. See `.agents/skills/SOURCES.md` for upstream sources and version notes.
